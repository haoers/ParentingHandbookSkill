# 分龄育苗手册

以“家长隔三个月回来，能依据哪个变化决定继续陪、少帮一步或及时介入”筛选内容。18岁向本人提问。

联系码由本项目提供获准用于成品的原图；当前版本如不设联系码，将扫码项目记为不适用。

## 接单与研究

- 打开[制作 SOP](references/production-sop.md)。新学段查第一、二节，单龄提纲或选题查第二、三节，样页和整册查第四节，已有册仅改字或排版时直接打开该页和第四节。
- 收到外审、家长反馈或多份修改清单，先打开家长实际拿到的最新版。把意见定位到页码、原句或页图；同一问题合并出处，记录取舍和落实情况。按[改什么、验什么](references/production-sop.md#review-intake)选择工作量。
- 从已有项目取年龄、在读状态、地区、教材、前后龄路线、已认可图稿与原始微信码。周岁与年级分别记录。对已给的信息直接使用。缺少入学地或学年会改变确切报名要求时，精确询问；同时完成不受影响的工作。
- 按请求停在提纲、一个选题、一张真实样页或整册。完整新年龄逐龄实读比较100篇不同适龄原文、复核50项视觉参考，记录实际读过的定位及取舍。新学段有缺口时才分批找200–350条种子。排版修订查受影响部分；保护、健康、政策、教材或分工图含义发生变化时定向回查原始依据。
- 先保留真实出处和原文定位，再写当页结论。高后果情形写具体保护人和动作。家长经验只用于发现问题，研究年龄范围、数值单位、地区、版次分别核对。尚无充分依据的内容放编辑台账。

## 单龄成稿

- 依次写学段、年度方向、四季度。对照前龄成品原句与页码，写清这岁新增的动作。换场景重练可注明延续。前龄或后龄未成册时标明对照了哪版路线；季度安排属家庭建议。
- 依 SOP 的六条主线和小能力检查主次。每季选一项小能力、一个代表场景、一个家长动作和一个可观察变化。园校状态不明又涉及学校流程，分仍在园／已入学各写一例；家庭共用动作可用一例。18岁改为本人行动、判断和选择支持。
- 测量已确认参考页，登记本册各级标题。页题、模块与可独立查找的小标题前配语义图标，同级统一字号与字体。真实表格连同表头、数字和多行组合逐格垂直居中、每列左齐，遵循已认可的浅底与插画画风。对新作或改选的位置，依[字号与图标选用](references/production-sop.md#visual-print)，为年度、每季、重点健康安全判断、关键主图或示意图、每条推荐资源各建独立位置，从至少十个可核候选中择一。普通新图标三选一，普通同义图标可复用并复检。无法配合当龄动作或打不开的素材重新找。
- 完整年龄册按已授权阶段推进。先用真实文字和插画做代表页；新视觉方向或新的阅读顺序请用户确认后推广到全册。记录换页或删并内容的去向。
- 交付提纲时附季度方向、邻龄承接和关键待核项；单项任务只交对应一行。交付完整 PDF 时同时报告核验范围。保留证据台账与发布记录供编辑续作。

## 最终 PDF 出版检查

1. 新作整册或重做关键位置时，先将关键位置对照[独立复核与退回](references/production-sop.md#review-gates)。在技能目录运行 `python3 scripts/check_selections.py 单龄编审.json --release`；多龄按授权顺序传入文件并加 `--order 3,4,5` 等对应年龄。每龄通过内容、视觉与装版后的数字终检，再放行下一龄。
2. 输出面向家庭的文件名，如 `5岁家庭育苗手册.pdf` 或 `5岁家庭育苗手册_首页.pdf`。从版式源头检查封面、页眉页脚、图层、水印、属性、书签和批注，登记真实状态到内部交接记录。保留家长所需的来源、就近保护提示和参考备注。
3. 在技能目录运行 `python3 scripts/check_release_pdf.py "文件.pdf"`，可在后面追加多份 PDF。脚本需要 PyMuPDF。根据输出逐项处理明确命中和待人工判读项，修正后重新导出重跑。环境无法执行时，按 SOP 第四节逐项人工复核并注明范围。
4. 按[版面核验接口](references/production-sop.md#layout-schema)运行 `python3 scripts/check_layout_pdf.py 版面.json 正式册.pdf`，同批跨龄加 `--also 版面.json 正式册.pdf`。独立对照纸面清点标题、语义图标与单元格，核完跨龄字级、列左锚与文字块中心，再渲染每页检查图片内文字、文字转曲、灰度和裁切。对完整册派生的单页核对渲染一致性、实际页码、二维码及链接。以两种分辨率的彩色／灰度全页图解码，核对项目原始二维码。将电子检查、物理打印、手机微信实扫和真实读者试读独立记录。
5. 如改字体、模板、健康表或派生首页，按[三个成品回归样例](references/production-sop.md#regression-cases)测试受影响的文件。交接首页分别显示实印、微信纸上实扫、首次家长试读和一季后回访的状态。只向用户报告实际完成的范围、修复点和待实测项目。涉及家庭实测的结论必须有对应实物或反馈。终版洁净检查通过仅说明文件可交付，四季全年效果须靠实际使用观察。
