**目录**　[任务分流](#workflow) · [外审与修改](#review-intake) · [研究投入](#research) · [季度成稿](#quarters) · [排版与交付](#publication) · [字号与图标](#visual-print) · [关键位置十选一](#key-selection) · [独立复核与退回](#review-gates) · [回归与续作](#continuity) · [三个成品回归样例](#regression-cases)

一本手册要经得起两次翻阅。第一次，家长找得到孩子在全程的位置和眼前最重要的一件事。三个月后再翻，家长看得出孩子哪一步有变化，知道可以少帮一步、继续等，还是需要靠近。以这两个用途决定选题和篇幅。

## 一、接到任务，先决定要做多少工作

| 收到的任务 | 从哪里开始 | 这次做到哪里 |
|---|---|---|
| 打开新学段，或课程发生影响多个年龄的调整 | 盘点该阶段已有来源与年龄覆盖，再决定是否建立共享候选库 | 形成阶段题目、来源、适用年龄和缺口清单。一个阶段建一次，相邻年龄复用 |
| 在已有学段做一个完整新年龄 | 读已确认的总图、能力索引、前后龄方向和该阶段候选库；只补这个年龄的空缺 | 按项目要求完成该龄100篇原文阅读比较、50项图表复核、四季度和真实文案样页，再进入整册与验收 |
| 只要提纲、选题或一张样页 | 按指定深度取材，标出验证范围与待核项 | 交提纲或样页。进度写明“已核哪些”，样页数据与整册分开计 |
| 收到外部意见或试读反馈 | 对照当前发行件、具体页和原建议，先分清事实、排版现象和阅读偏好 | 按下表确定要改的内容、相邻页面和待验证事项 |
| 修改已有册 | 分清改变了呈现、行动含义、适用对象还是数据来源 | 改字号或缩短等义标题，直接打开实稿并复核受影响版面；改保护顺序、教材结论、健康数字或图例含义，重查对应原文、相邻措辞和关联图表 |

**任务完成的标志。** 先确认本次交付物。只做一项选题，用一行说明出处、动作和观察即可。已有确认内容与样页时，将其版式落实到其余各页，再对整册做终版检查。先确认制作源与家长当前使用的版本相符，再修改并重导。若只有旧源，保留正式文件作对照；记录实际修改入口，逐页查清图文差异后再交付。

**复用的最小单位。** 全系列共用五阶段、六主线、能力索引、年龄图规则、印刷和证据格式。学段共用学校与生活的典型场景、家长角色、教材与标准目录。单龄重写年度方向、四季度进展、热点边界和家长动作。局部修改记录“改动前后、影响哪页、复核了什么”。证据登记、页面渲染和二维码解码方法可以沿用；调用旧脚本前先看支持年龄、输入文件与硬编码断言。

### 外审意见怎么处理，改后查什么

在【逐条取舍】沿用同一个编号记录附件出处、所指版本／页、是否采纳、实际改动和核验凭据。相似意见合并，意见冲突看它会改变家长哪个决定。先打开家长拿到的发行件，再找到与这版匹配的制作源；来源不同先核对页图、文字和链接。比如3岁年龄在现行首页左侧，文本提取却排在主题后面，看过页图即可把这条意见记为「现版已做到」。只要求先提建议时停在取舍清单。

| 改动 | 操作和验收范围 |
|---|---|
| 润色或局部排版 | 对照原页检查“谁、在哪里、做什么”及动作含义。查修改行与邻栏换行、图标和灰度。家长要采取的行动改变时，转相应内容项核证。 |
| 新增或替换主图、关键流程或推荐资源 | 从该位置的候选池复核至少十个有效选项，记录为何选中、图中谁在做什么或资源实际如何使用。沿用同年龄、同位置、同用途的已审素材，引用原记录，复核本页搭配、入口与适用性。 |
| 改生长表或保护话术 | 数字逐格回查适龄标准的表号、月龄、性别、单位和分位，另试一个表中未列的月龄。保护话术核原文，再让独立审读者指出孩子能做什么、谁须当场接手。检查相邻卡片有无相反指示。 |
| 改学习策略、年度或季度重点 | 核实际在读状态、课标／教材适用范围，区分家庭建议。并排读上龄末季与本龄首季，请审读者说出儿童新增的动作及家长能少帮哪一步。 |
| 改导出、字体、模板或首页 | 列出实际使用该模板的共享总览、分龄主册和已分发首页，在最终文件上跑下文回归。只发主册的年龄无须为测试另出单页。 |
| 改二维码或证据入口 | 复核实际用途和目标，确保纸上保留行动或可检索出处。二维码另按第四节核对载荷，登记手机微信扫印张的结果。 |

## 二、哪些值得脑暴，哪些值得搜几百条

“候选种子”指一个待查的公开原始链接或书目。一个问题可以有多个种子，一个种子也可能与几个年龄有关。脑暴的题目数、发现的链接数、实际读完的不同原文数、入版条目数分别统计。

| 内容 | 建议投入 | 最终选什么 |
|---|---|---|
| 全系列框架和阶段标签 | 复用既有五阶段、六线和100选10的阶段标签底稿；整体创意已有50选10 | 某阶段存在明确空缺或家长反复误读时才重开该组。首页保留每阶段1–3个标签 |
| 新学段的热点、真实场景、学习断点、家长困惑 | 缺共享库时，建议分批发现 **200–350条候选**；先盘点教育、健康、安全第一手目录，再补家长问题、教材目录和年龄适合的资源，优先补缺口 | 按年龄、地点、家长要做的决定分组。得到可让数个年龄共用的研究入口；首批已覆盖的方向不用重复采集 |
| 单龄年度重点、季度候选和常见边界 | 可先合计脑暴30–50个，再为年度、每季和重要决策单独补足十个有效备选。从家里、学校或园所、同伴、公共或线上生活切入，再反查六条主线 | 每季选1项小能力；全年另选约3–5个值得留存的热点或低频高后果场景。四个季度不必分属四条线 |
| 主科学习承接 | 对该年级、学期和实际教材适用的**每门主课脑暴20项，留2–3项家庭可做的**；已有模块直接复查差异 | 优先选家长看得到、一个提示能帮上忙、以后能迁移的动作。标出上一单元基础和下一次用途。学前从生活、游戏、阅读选题 |
| 兴趣、游戏、书和影视、是否报班 | 每个拟刊资源位至少查十个真实作品或节目，从中各选一项；可从阶段库重查并补新 | 长期兴趣先看孩子愿不愿再回来。家长读物、儿童读物、影视各至多1项，核题名、版本或集数、可获得性及具体用途。选班给进入与退出条件 |
| 保护、求助、健康参考、补充剂、招生与政策 | **精确查原文**。数字直查当期适用标准原表；安全处置直查适龄权威指南；教材直查对应课标与用书；地方政策核地区、年度和适用对象 | 只保留足以支持眼前行动的内容。家长讨论可发现问题；点击量不决定做法。健康热点缺直接适龄证据时留底稿，疑似个体健康问题写清求助渠道 |

表中200–350、30–50和3–5是建议工作量，可按实际缺口与资料重复度调整。**逐龄100篇不同原文和50项视觉参考是现行整册要求**。公共池里适用的材料可计入，前提是本次重新核对并写下该年龄的发现或取舍。每项视觉参考可以是作品、组件或规范；50项复核只为筛出真正帮助阅读的表达。

**示范一轮6–8岁选源。** 可先用“入学适应＋课堂指令”“一年级上册＋实际用书＋单元”“课间相处＋同伴冲突”“自己整理＋家长提醒”打开四个方向。首轮看能否同时找到制度原文、教学内容、孩子日常动作和家长真实疑问；若大部分是相同的学科培训文章，下一批转向缺失的指南、教材或生活场景。采集到题名和原始链接即可先去重，值得用的再读全文并定位。

### 一条线索如何走到印刷页

1. **先列家长问题和空缺。** 以“年龄／学段＋地点或事件＋家长的选择”检索。批量收公开目录、站点地图、机构专题和书目；论坛或社交平台用于理解家长措辞，登记共性问题即可。
2. **去重，辨原文。** 依次按原始链接或 DOI、发布机构＋题名＋版次核对。转载、翻译、附件并入同一来源。同一份标准可支持多条主张。修订版标现行与旧版的关系。仅有摘要、目录或打不开正文的候选留“待查”。
3. **把发现写成可复核的一句话。** 登记来源编号、原文定位（页／表／单元／小节）、年龄或年级、地区和版本、能支持哪一句、有什么条件。资料冲突先查版本、人群与使用目的；未解决的从家长页撤回，保留原因。教材分开写课标学段目标、本册实际单元、家庭建议。人教版需落实到册次和单元；信息未知可出共用方向。用户指定某地入学材料而地点、区县或年份未知时，先补齐会改变答案的字段；通用占位只在编辑待核表中保留。
4. **选入或舍弃。** 先保能避免伤害或错过重要支持的判断，再选反复用得上的事和能延续的兴趣。相似题留下改变家长决定的那一项。每项写纸面去向或舍弃理由。图表台账另记“想帮家长看懂什么、采用哪一处或为何舍弃”。
5. **何时停搜。** 该学段的每个关键问题已有合适的研究入口、继续一批多为重复时，先停广搜，定向补空。完整新龄须同时达到100／50、覆盖重要场景、能追溯入版主张；即使候选已超350条，未解决的关键问题仍需定向查或从版面移除。记录候选量、去重原文量、实读量、采用量和未决项。

**一张底表足够起步。** 每一行连接“题目编号／主线与小能力｜年龄·年级·地区｜场景与家庭决定｜来源编号·原文定位·日期｜来源事实或编辑建议｜纸面句子·页码或弃用原因”。内部差异、材料及取舍保留在底稿，PDF仅呈现家庭需要的判断和简短证据入口。

<a id="key-selection"></a>

### 关键位置怎样十选一

新做整龄时逐页盘点全部关键位置，每个位置各自比较至少十个实质不同的有效候选，选一个，记下理由。修订既有册时标明新增、换选或沿用。新增或换选执行十选一；沿用同龄同位置已审方案时引用原候选记录并复检。原记录缺失或用途、年龄、动作改变，重新核选该位置。共享图库或研究池可以复用，每个位置仍需按本页目标独立取舍。普通导航图标沿用三选一；重复出现且含义相同的普通图标记录出处与本页复检即可。

| 关键位置 | 怎样算一个候选 | 选入条件 |
|---|---|---|
| 年度方向、四个季度各自的核心动作、改变家长判断的健康或保护提示 | 同一位置上真实可采用的另一种重点、生活场景、引导动作或判断问题；候选写清“谁在什么场景做什么” | 家长一眼知道何时做，三个月后看得出什么变化；衔接前后龄。换同义词、换人名或重排顺序仍算一项 |
| 首屏主图、说明关键动作的场景图、安全求助图与关键流程 | 十幅实际可查看的图、分镜或流程小样，各有可定位文件或原作入口，并能说明动作、角色或构图的实质差别 | 最终印刷尺寸下能读懂动作和成人职责，和彩色／灰度正文、相邻画风适配，权属支持实际用途。换色、翻转、裁切同一图算一项 |
| 印给家长的每本书、绘本、每部影片或具体节目 | 同一推荐位有十项可识别的作品，逐项记录题名、版本或集数、适龄边界、可访问入口和家庭用法 | 打开出版社、作者、图书馆、播出方或机构原页核对。旧链接失效、实际片段不对应或不适龄时，换检索关键词、换来源补足 |

**事实核对。** 对相同权威事实可比较十种有区别的家庭行动或纸面表达，事实本身直接回到当期适用的中国标准、指南、教材或法规原文。按年龄、性别、时间、单位和表号逐格复核。安全流程中固定的保护顺序必须准确，图样和可删减的编辑说明可以比较。只有一项适用标准就如实记录这一项。

**退回重找。** 先剔除重复或失效项再数十个。人数、动作或地点与正文对不上，人物看似把保护责任交给孩子，或资源得不到、无适龄内容，一律退回。保留问题、旧图／资源和替换原因，定向补入有差别的新候选，再请独立复核者看替换后的整页。必要的安全健康内容若无足够依据，留待核并明确卡点。可选资源暂缺合格作品时可删去该推荐位，在台账记明。

## 三、从全局拆到一个季度

从六条固定主线挑出本季最值得关注的一项小能力。下表沿用项目中的候选能力词表；跨龄核对用同一组词，印给家庭时换成熟悉的场景和动作。

| 固定主线 | 可跨年龄追踪的小能力 |
|---|---|
| 身心健康与调节 | 表达身体需要、照顾作息与活动、找到情绪恢复办法 |
| 独立生活与安全 | 照料日常事务、管理物品和钱、识别风险并求助 |
| 品格与相处 | 表达与倾听、分工守约、尊重边界并修复冲突 |
| 兴趣、见识与创造 | 主动探索、持续投入并拓展见识、表达发现或创作 |
| 学习方法与思考 | 提问查证、安排步骤与收尾、回看并调整方法 |
| 自主判断与选择 | 说出偏好与标准、比较选项与代价、作决定并调整 |

把当岁的四行放回16个年龄×4个季度的目录，查看相邻两岁是否重复、跳级或长期缺失某条线。健康、快乐与已有兴趣贯穿全年。

| 学段 | 选题首先去哪里看 | 家长动作随阶段怎样变 |
|---|---|---|
| 3–5岁 | 家里自理、园内游戏、公园探索 | 示范一次，给孩子做的机会；危险时大人接手 |
| 6–8岁 | 仍在园或已入学、课堂指令、物品和同伴 | 留下一个可用的提示，观察孩子哪一步已经能自己做 |
| 9–11岁 | 多步骤作业、小组分工、兴趣能否持续 | 和孩子一起定位卡点，让孩子选办法、试过再调整 |
| 12–14岁 | 同伴关系、个人空间、线上交往和课程转换 | 先听本人判断，协商边界和可求助的人 |
| 15–18岁 | 学习选择、生活安排、花费和校外事务 | 支持本人比较选择、承担后果和主动求助；18岁文案面向本人 |

表中是编辑找题入口。单龄先填三个短句：“此前已经练过什么／这岁孩子多做哪一步、家长可少帮哪一步／下一岁如何接上”。在底稿贴出上一册对应原句、页码和版次，圈出本岁多做的动作；仅换时间、地点或换近义词的候选退回。若上一项在新环境中确实需要重练，则明确写作“延续”。邻龄尚未成册，用已确认的年龄路线作比较，把推演标成待验证。3岁从入册基础起写；18岁写本人下一种生活情境。转衔年龄先确认是否入学、升学或转轨；在读状态不明确且采用园校流程时，分别给仍在园、已入学的场景，练同一个动作；使用园校皆适用的家庭场景时，一例即可。

每册先定一句年度方向。四个季度从生日当天起，依次写**第1-3个月、第4-6个月、第7-9个月、第10-12个月**。每行给出“本季练什么／一个代表场景／家长怎样帮／看到什么算进展”。进展尽量和孩子上次的表现比较。三个月回看时，有机会并能主动做，可以少帮；机会少或仍需提醒，可延续上季；涉及保护的条件，就近写谁接手。家庭无需打卡填写。18岁把季度栏改成“我准备做什么／我怎样判断有进展／我需要谁支持”，试读请本人作答。

## 四、从真实文字样页到可交付 PDF

| 顺序 | 编辑要交出的东西 | 怎么判断可以往下走 |
|---|---|---|
| ① 确认范围 | 单龄、对象、任务深度、地区与在读状态、已有素材、前后龄资料；标出未知项 | 能决定是补证、改版、做样页还是做整册。上次已确认的风格可作本次起点 |
| ② 定题与核证 | 年度方向、四季候选、热点取舍、邻龄承接及证据底表 | 当季只有一个核心动作；教材、健康和保护句各有对应原文；当地个案和编辑选例有明确身份 |
| ③ 排一张真实样页 | 用真文案、真实字号、真实插图和原始微信码试排；给出其余页用途 | 先确认首页能从全局找到当季。新视觉方向、不同学段的画风变化，以及真实文案样页供用户确认后再铺整册 |
| ④ 全册自检 | A4纵向2–3页。首页给全局、年度、季度；后续页按本龄家长最常查的场景和决定组织 | 对照上一稿逐项记去向。每张场景卡一个地点；孩子的动作和大人的责任均能辨认；只给证据下划线。末页右下角约25字的适用说明 |
| ⑤ 试读、印刷、验收 | 记录电子检查、物理打印、微信实扫、家长试读、用户验收的各自状态 | 渲染每页，检查字体、裁切、链接和灰度；最终整页按150／300 DPI、彩色／灰度四种组合解码，比对原二维码。用高白A4、实际大小打印首页，换版后涉及二维码的页也实扫。实物未测写“待实测” |
| ⑥ 交接 | 交本次请求的文件，注明范围、版次、修改点与待核项 | 单龄过验收后归档。交接条写“已完成／待核／下次从哪里开始”。进入下一个年龄按其授权范围推进 |

**家长会收到几份。** 每个年龄默认一份2–3页A4主册。确有单独打印或分发用途时再保留首页，优先从同版主册派生，计入本龄份数。每龄尽量不超过三份。3–18岁共享速查只计一份，编辑工作簿单独交接；登记时分开写文件数和页数。

**图怎么选。** 阶段位置沿用3–18岁连续16根逐龄增高的细柱、五段浅底、当前年龄描边及短图例。柱高编码年龄，分层来自各阶段选取情境中的分工，只能表达编者选例。顺序影响行动时用短流程、编号和递进浅色。并列判断用表，人物互动或示范动作时用场景插画。低龄沿用认可的温馨手绘风，大龄换适龄形象。重点用亮浅底和清晰深色字，当前年龄或步骤在灰度下也可辨。

<a id="visual-print"></a>

### 用字号找重点，用图标找场景

**先量参考页，再定全册字级。** 6岁正式册首页年龄为38.5磅、年度标题26.6磅、模块标题18磅；第二、三页的页题为27.8磅、栏目标题为17.4磅。保留家长认可的标题辨识度、深绿与炭灰、附近的语义图标和浅色留白。新册先给每个标题分角色，同一级在各页和同批年龄固定字号、字体和字重。封面年龄数字可设独立样式。长标题先调整可用宽度或换行，仍放不下再缩短等义标题；禁止逐个缩字塞进框。沿用的图标和人物插图保持相称的线宽、轮廓和明暗。

| 版面角色 | 排法和图标职责 |
|---|---|
| 页标题、栏目标题 | 同级各用一个固定样式。每个标题前放一枚符合主题的图标，图在标题左侧，留出空隙。系列标识、页角人物和二维码有各自用途，不能顶替标题图标 |
| 场景小标题、季度动作及可独立查找的卡片题 | 给家长用于定位的标题配具体物件或动作图。先按同一角色比较六岁参考页，再试本龄的用词；同级对齐起笔、大小及字重。避免同一区块数次重复同一标记 |
| 纯字段与图表标识 | 月龄、单位、表头、步骤序号、说话人、证据和页码保留文字标签。需读出顺序的流程保留编号。统计图的坐标刻度、组名和图例按数据对应，不套正文表格的左对齐规则 |

**表格按格居中、按列左齐。** 对季度表、健康数值、学习策略、资源行和所有带表头的分栏，逐格写明真实行与列边界，再给同列文字统一左起笔。单行、多行、合并表头、月龄、单位与数字一并左对齐。在每一格中，按印出的文字整块计算上下留白；两行的分行、动作与场景小字、不同字重和字号的组合均按整块居中。不能把各行单独放到同一基线上。图标占用独立前缀栏时，保留整列相同的文字锚点。行高不足时重排或加高整行，链接热区跟随文字。表格之外的流程箭头、编号和柱图刻度仍各自贴合动作顺序或数据位置。

**从成品做几何核验。** 每册随排版底稿保留标题清单和单元格边界，两者以最终PDF页面左上角为原点，尺寸用磅（pt）。标题每项记录页码、角色、标题文字、排版字级、文字框及标题前图框。表格每格记录页码、表名、行列、真实格框、统一左锚和折行。数字、纯表头及组合单元格都需入表。用 `python3 scripts/check_layout_pdf.py 版面.json 正式册.pdf --json 检查结果.json` 从实际 PDF 印出的字形核对；同批可追加 `--also 第二册.json 第二册.pdf` 检查跨册字级。命令需要 PyMuPDF 和 Pillow，清单格式与判定边界见[版面核验接口](#layout-schema)。

**普通栏目图标三选一。** 承担年度主旨、展示关键动作、表达危险边界或保护步骤的图，即使印得很小也按[关键位置](#key-selection)处理。

1. 写出家长要找的场景或动作，优先找文案里出现的物件。栏目图标帮家长定位，人物插画用来讲动作或关系。一个清楚的入口配一个图标即可。
2. 从同画风图集、已有项目素材或自绘草图取三个有不同轮廓或物件的实际候选。把三个图与同一个栏目标题、相邻插画并排，按成品大小各看一遍彩色和灰度。仅换颜色算同一款。先比含义能否看懂，再看轮廓、线宽、圆角、视角和浅底用色能否与邻图搭配。留出图与文字、二维码之间的净空。
3. 选一款，记一句采用理由与其余候选的主要歧义。小尺寸下线条粘连就简化；三款都容易看错时，为标题重找具体物件或重新绘制；纯字段按上表处理。保护场景必须能从旁边的字读出“谁保护、怎么做”，避开可能暗示“孩子要独自制止或识别危险”的图形；健康数据表优先留给单位与数值。
4. 存一行编辑记录：页码与栏目｜三个图样或文件位置｜采用图与理由｜素材来源及可用依据（项目自绘或外部授权）｜实际尺寸与彩色、灰度检查结果。按主要含义和形状归档。已在样页确认的普通同义图标可直接调用，放到新背景、缩到新尺寸后重看；换含义或换画法时重新比三款。编辑记录单独保存。

**给另一位家长的纸面试读题。** 不讲解，先请对方按孩子生日找当季，指出“我做哪一步”“什么变化说明可以少帮”。再请找到一个可以等待的情况和一个应及时介入的情况。18岁请本人找出“这件事我自己决定哪一步、何时找人支持”。若对方要重读标题、靠猜颜色、或以为孩子必须在本季达标，记下原词并改。一次试读能发现摩擦；三个月后是否真的回来翻需实际回访，单独记录。

<a id="layout-schema"></a>

#### 版面核验接口与放行条件

JSON 顶层使用 `headings`、`cells`、`exceptions`，页码从1开始，矩形为 `[左,上,右,下]`。标题用 `{page,role,text,box,size,font,icon:{name,box}}`；文字框覆盖本标题。表格单元用 `{page,table,row,col,box,left,lines:[{text,size,font}]}`，单一字级的行也可直接写字符串。`left` 是实际页坐标，`box` 须采用表格的真实格框；多行共用一个格。按页、表名、逻辑列号比较各行的格边和文字左锚；合并表头、分面等具有不同列网格时，显式设不同的 `grid` 值或表名。字体可写 PDF 字体名或 Bold／Regular（用于核同一角色实际字体）。图示例外逐项写 `{page,box,reason}`。编审先列页面角色和栏名，独立审读者再对照原稿，查找缺项、被误当成纯字段的标题，以及未被列入的数字或表头。位置声明不能代替纸面核对。

1. **文字。** 用最终 PDF 查实际文字及其位置。一个角色只用一种字号和字重。程序对比实际字体，并仅容许PDF传输造成的细小取整（字号0.12磅）；超过即退回。抽查标题换行后有没有越界、落单或挡住图。多龄各用不同字库子集时，分开注册或隔离导出，从实际多龄入口重导，逐页核空字符、替代符和漏字。纯样式改版按输入顺序为每册传一次 `--source-pdf 原稿.pdf`，对照原稿逐页字量；另按本页输入文案回查句子或数字顺序。若确有文字调整，先登记 `text_changes` 的页码、原句、新句及原因，再核实际差异。使用两种独立渲染器（如 PyMuPDF 和 Poppler）各自成图，重点看每个年龄特有的字，辨认是否缺笔、空白、错字。
2. **图标。** 程序查标题左侧有可见图形及足够灰度墨迹，并检查图文间隙和中心。判断“图是对的”须按成品大小独立读图，复核者应能从小图和标题说出同一个动作或场景。不得因图标数量够多而放行。
3. **对齐。** 用实际文字起笔核左锚（允许1磅取整差），用三倍渲染下的可见墨迹核上下留白（文字块中心距格中心至多1.5磅）。这两个限值是本系列打印排版的制作公差。图库缩放、折行、字体或内容有变，须重导并复核受影响的格子。不能用扩大公差或把格框缩成字框使坏版通过。
4. **独立试读。** 同时查看常用纸面尺寸下的彩色与灰度全页，包括漏登标题和普通字段。检查器能发现未登记的显眼大字；仍须人工逐项看小标题和图标含义。记录本次年龄和页码、实际复核位置数、修正及复验。纸张实印另列状态。

<a id="review-gates"></a>

### 独立复核与退回

1. **预列位置。** 编辑在选材前写清页码、位置编号、家长要解决的问题与类型。重做年度手册至少逐项盘点年度、四季、主要保护／健康判断、主图、关键流程，以及实际刊出的每条推荐。记录上龄已有动作、本龄新增动作、下龄如何衔接。批量时依授权顺序逐龄放行。前龄有修改影响承接，重查下一龄首页。
2. **内容初审。** 作者交候选原件、取舍和逐条出处。另一位编审或独立审读任务核对适龄性、家庭可行性、证据和选用资源，抽回十选一表检查失效、重复及表面改名。高后果句、数据和资源题名逐条验；打不开适用原文则退回。
3. **图文复审。** 独立于制作者的审读者先读最终图样中的角色、动作、顺序，再与正文、同栏标题和邻图对照。在实际尺寸查看彩色与灰度，检查保护责任、人物年龄、图标线条与二维码净空。读错动作或找不到位置时，回到相应备选重选／重画并复评。
4. **数字终检与放行。** 对最终文件核页、文字去向、邻龄、出处和网址、健康数值原表、图像和标注、正式用词、四种二维码解码；运行候选台账、版面几何和 PDF 洁净检查。版本、作者、复核者、发现问题、修订和复验结果均可追溯。任一关键问题未解，本龄留在修改队列。查看数达标，只证明有足量候选。家庭纸张实印、手机微信实扫、真实家长试读另记实测或待实测。

**可复跑的候选核对。** 每册存一个 UTF-8 JSON。顶层设 `age`、`previous`、`next`、`author`、`inventory`、`slots`、`reviews`。预列的 `inventory` 每条为 `id / kind`。每个 `slots` 条目含 `id / kind / prompt / candidates / winner / why`；类型为关键文字 `info`、关键图 `image`、推荐 `resource`、普通新图标 `icon` 或普通复用件 `reuse`。每个候选写 `id / label / ref / reason`。网址指向具体原页，本地文件相对台账或用绝对路径，图册或来源表可用 `文件#页码或条目` 定位。相同成品图文件按内容去重。

依次登记 `reviews` 中的 `content → visual → digital`，每项写 `stage / reviewer / status / evidence`。电子终版放行值为 `pass`，审核证据指向真实复核记录。可在 `fieldwork` 另存实物测试，如 `{"纸张实印":{"status":"pending"}}`，实测完成用 `done` 并附 `evidence`。先运行 `python3 scripts/check_selections.py 单龄编审.json`，供定稿时追加 `--release`。多龄检查示例为 `python3 scripts/check_selections.py 3岁.json 4岁.json 5岁.json --release --order 3,4,5`。机器可核对位置、数量、重复、选用编号、文件存在与审签顺序。网页是否真的打开、同一作品异名、图能否传达正文、年龄承接好不好和是否实际印过，仍需查看相应原件与审读记录。

### 正式交付前，拿将要发送的文件做最后一遍检查

| 检查面 | 通过条件与处理 |
|---|---|
| 文件名与内部属性 | 整册用“5岁家庭育苗手册.pdf”这类名称，单页可用“5岁家庭育苗手册_首页.pdf”。在阅读器打开标题和书签，核对作者填写的标题、主题、关键词和批注。版本与流程状态记入交接表。 |
| 页面与素材 | 从真实导出文件逐页提取文字，同时查看整页渲染及页角。检查封面、题头、页脚、图像内字、水印、占位图、编辑批注、转为轮廓的文字。“排版提案”“草稿版”“内部校样”“待补图”等制作标记应从源文件修正并重新导出。正常学习语境如“草稿纸”按原意保留。面向家庭的适用提醒、保护提示与来源需保留。 |
| 工具判读 | Skill 自带 `scripts/check_release_pdf.py`，可一次传整册及独立首页。CLEAR 表示可提取文字未命中，仍要读图；BLOCK 回到源文件修正；REVIEW 查原句或渲染，记录判断；ERROR 修复文件或工具后重跑。没有适合的 Python 环境，可用阅读器检索、查看文档属性、逐页读图，记录采用的办法。 |
| 关联版本 | 同时导出了整册与单页，两份均检查。比较首页渲染、保留的链接和二维码载荷。页码按交付用途核对。二维码在150和300 DPI的彩色、灰度图各读一次；手机对着实际纸张扫码另计。 |
| 交接记录 | 对每项实测注明对象、方式、结果。检查链接位置、是否指向预期目标，与目标网站当时是否响应分别记录。家庭实物打印、手机实扫、真实读者试读各自标“完成”或“待实测”，这些状态只在交接记录中出现。 |

<a id="continuity"></a>

## 五、样本、回归与续作

新年龄先按最能暴露问题的一个场景复核。五岁可回查原句，六岁可检查园校差异，文字与视觉样页通过后再铺整册。可在相邻年龄上验证“同一能力多做了一步”，同时在18岁用一条选择类文案检验读者与决定权是否已转为本人。下次交接保存三项信息：本次改了哪条规则、哪种情况仍需人来判断、下一次可以直接复用哪张表。

<a id="regression-cases"></a>

### 三个成品回归样例

核对数字前先打开对应标准原表。本节的6岁示例使用附录A表A.4，查女童年龄别身高的P50列。[国家卫生健康委《7岁以下儿童生长标准》](https://www.nhc.gov.cn/wjw/c100179/202211/5522cdcd113a4c3a89e0acf318818460/files/1733125082501_81468.pdf)

| 在什么时候跑 | 拿什么检验 | 通过与退回 |
|---|---|---|
| 字体或导出链改变 | 从最终PDF复制一处中文标题和另一页的一句正文，用两种独立引擎分别渲染逐页查看。共享双页曾能复制文字、在其中一个引擎却大面积空白。 | 两边能认出与原文相同的字，周边的底色与插画不算字迹。字不可见、替换或错形须修复；工具识别证据不足就打开对应局部目检并记录。 |
| 新做或改生长参考表 | 对照适龄标准，在6岁样本查6岁6个月女童的身高中位数，再查6岁11个月。换年龄时从新标准各选一个已列、一个未列的年龄。 | 对样本，前者能在正确表格找到120.6厘米；后者回到历次实测记录，有疑问问儿保。另取一份测试副本，将81月龄数值移到83月龄，复核须能指出该行。补算、借用邻行或把参考点当成诊断线，均退回。其他年龄使用其适用的出处和数值。 |
| 主册首页、链接、模板或导出有变 | 把将要交付的主册第1页与既有独立首页并排，比文字、尺寸、图像和可点区域及目的地。普通二维码另按原码复核。 | 直接派生页应一致。若只是过时的链接、画面却一样，也须重新从最终主册派生、复验。经确认的单页专用页码或导航须登记差异与依据后单独复核。 |

检查工具使用 PyMuPDF、Pillow、pypdf 和 Poppler 的 `pdftoppm`。在技能目录运行下列两条命令，文件名可换为本次的发布路径。短语选各页实有、能唯一定位的中文，优先覆盖不同字重。前一项抽检选中字形，整页仍须读一遍。后一项适用于直接派生的首页。两项均可加 `--json 报告.json` 保存结果。

```sh
python3 scripts/check_pdf_regressions.py ink "3至18岁家庭成长方向_家长双页速查.pdf" --probe '1:每个年龄先顾哪一步' --probe '2:家庭判断'
python3 scripts/check_pdf_regressions.py cover "6岁家庭育苗手册.pdf" "6岁家庭育苗手册_首页.pdf"
```

`PASS` 表示所选项目通过，`FAIL` 记录发现的差异，`REVIEW` 交人工核验。工具缺失或短语定位失败时，写明未验的部分。

**重现两个数字故障。** 仅在临时副本中做：把一行可提取的中文设为不可见文字后检查该行；另拷贝一份首页，只改一个链接的目的地。前者应被识别为缺字，后者即便像素与文本相同，也应报告链接差异。保留原发行件和正常样例一并对照。

**现场反馈怎样回到下一版。** 在阶段首页分别列出纸张实印、微信对纸实扫、初次家长试读、三个月回访，以及每项缺的证据。适用项记「待实测／已实测」，已实测附版本、页码和结果；本版不适用的项目在交接首页写明原因。编辑的电子试读另记。首次试读请家长找到本季、说出准备帮哪一步；回访请其举一个变化，说自己决定继续、少帮或求助的原因。误读或找不到入口时，把原话、页码和复测结果写回原意见编号；新问题才建新行。

### 六岁单项试跑记录

**输入**　刚满6岁，在读状态未知。只做一个季度选题。  
**回查**　五岁终稿第1页、第10-12个月已写“能说出哪一步没听清，也愿意自己开口问”。首轮候选“问得更具体”与它重复，退回改写。  
**本季可试**　问清以后，自己接着做。仍在园，收积木时问清盒子放哪层，自己放回去；已入学，交画时问清放哪一摞，自己把画交过去。家庭对应动作是答孩子问的那一处，留时间让孩子接着做。下次回看，观察答完后孩子是否还需大人领着做。  
**核验范围**　回查了五岁纸面，并核对教育部将幼儿园入学准备和小学入学适应分别安排的依据。季度选题、两个场景和“少帮一步”均为编辑建议。本记录只覆盖该次选题试跑。[教育部指导意见，第三部分第（一）（二）项](https://jyt.nx.gov.cn/zwgk/zfxxgkml/ywjy/gzwj/202204/P020220414649820804496.pdf)

**六岁接七岁的编审试读。** 对照六岁首页「接到7岁」和共享速查的7岁行。六岁关注问清后自己开始，七岁进一步观察中断后能不能接着做完。可用「收画具时去喝了水，回来能接着把笔放回盒里」检验选题。首次试读听家长说准备等还是提醒，一季后再问实际发生过哪一次。这里记录的是编审试跑，家庭效果待真实反馈。

**另外三类任务的适用范围。** 等义缩短标题，可直接进入原页；地方入学材料缺入学地与年份，只能保留待核项。18岁回看题改由本人回答。首轮据此补齐了任务入口、缺资料时的交付状态和18岁读者规则。
