## 打印以后怎么用

1. **第一次看首页。** 先看成长全图，再找到生日后对应的三个月。选一件平时就会发生的事，从「家长怎样帮」那一列开始。
2. **遇到具体问题再翻后两页。** 和同伴起冲突、需要向大人求助，或对学习进度有疑问时，找孩子所在的场景，看看何时可以让他试、何时需要大人接手。
3. **三个月后回到同一件事。** 上次需要你指给他看，这次是不是提醒一句就够了？根据实际变化决定继续陪、少帮一步，或者换个更合适的目标。

打印时选 **A4 纵向、实际大小（100%）**。保留电子版，里面的依据链接也可以点开查阅。
